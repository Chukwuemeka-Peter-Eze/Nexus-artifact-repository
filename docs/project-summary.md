# Project Summary

## Overview

This project demonstrates the deployment, configuration, and administration of a Nexus Repository Manager on an AWS EC2 instance.

The implementation focused on building a centralized artifact repository capable of storing, managing, and distributing software artifacts while exploring repository management, storage configuration, REST API interactions, and artifact lifecycle management.

The entire environment was deployed, configured, validated, documented, and tested through hands-on practice.

---

# Objectives

The project was completed to achieve the following objectives:

- Deploy Nexus Repository Manager on AWS
- Configure the application for production-style operation
- Create and manage different repository types
- Understand Blob Store architecture
- Configure Cleanup Policies
- Explore Nexus REST APIs
- Understand Components and Assets
- Publish artifacts
- Document the complete implementation
